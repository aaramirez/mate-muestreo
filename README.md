# Muestreo y control de calidad

Cómo se elige una muestra de una población finita y cómo se vigila un proceso: muestreo aleatorio simple, estratificado, sistemático, por conglomerados, en etapas y doble, estimadores de razón y regresión, marcos imperfectos, respuesta aleatorizada, captura-recaptura, gráficos de control y planes de muestreo de aceptación.

**Ver en línea:** https://aaramirez.github.io/mate-muestreo/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
